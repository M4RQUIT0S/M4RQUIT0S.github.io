AgroTrace, livestock traceabilityAgroTrace, trazabilidad ganadera

A multi-tenant web platform for Argentine cattle farms. Each animal carries an electronic ear tag. AgroTrace reads that tag from the field, stores what happened to the animal, and sends its movements to SENASA, the national agri-food authority. I designed, built and shipped it end to end. Una plataforma web multi-establecimiento para campos ganaderos de Argentina. Cada animal lleva una caravana electrónica. AgroTrace la lee en el campo, guarda lo que le pasó al animal y envía sus movimientos a SENASA. La diseñé, la construí y la puse en marcha de punta a punta.

  • Hardware limitLímite de hardware

    Browsers can't reach every readerEl navegador no llega a todos los lectores

    Some tag readers use Bluetooth Classic (SPP), and no browser can connect to it. I found this while testing real hardware, so the app works as a PWA over BLE and has a native Android path for SPP readers. Algunos lectores usan Bluetooth Clásico (SPP), y ningún navegador puede conectarse a él. Lo descubrí probando hardware real, así que la app funciona como PWA por BLE y tiene una vía Android nativa para los lectores SPP.

  • Bug I tracedBug que rastreé

    Writes that failed without an errorEscrituras que fallaban sin error

    Some edits were being lost. I traced it to supabase-js, which returns server rejections as values and does not throw them. I fixed the sync queue and added regression tests so it stays fixed. Se perdían algunas ediciones. Lo rastreé hasta supabase-js, que devuelve los rechazos del servidor como valores en lugar de lanzarlos. Corregí la cola de sincronización y agregué tests de regresión para que no vuelva a pasar.

  • SecuritySeguridad

    Permissions enforced in the databasePermisos aplicados en la base de datos

    Workspace roles (admin, user, read-only) are enforced with Postgres RLS. The page also has a strict Content-Security-Policy, and CSV/Excel exports are protected against formula injection. Los roles (admin, usuario, solo lectura) se aplican con RLS de Postgres. Además hay una Content-Security-Policy estricta, y las exportaciones CSV/Excel están protegidas contra inyección de fórmulas.

  • No public APISin API pública

    A bot for a government portalUn bot para un portal del gobierno

    The government portal has no API, so a Playwright service submits the movement reports. It runs in Docker with health checks on Google Cloud Run. El portal del gobierno no tiene API, así que un servicio con Playwright carga los movimientos. Corre en Docker, con health checks, sobre Google Cloud Run.
